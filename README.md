# Dicionário de Dados Corporativo - Sistema de Gestão de Vendas da KaBuM!

O Dicionário de Dados Corporativo - Sistema de Gestão de Vendas da KaBuM! é uma aplicação web desenvolvida como projeto acadêmico do Centro Universitário Fundação Santo André sob a orientação do Prof. Diego Marques De Carvalho. O sistema conta com alternância de temas claro e escuro, navegação responsiva, barra de pesquisa em tempo real para filtragem de atributos, além de recursos interativos avançados como um visualizador de DER com suporte a zoom e pan e um painel para consulta e cópia do script DDL em MySQL InnoDB com destaque de sintaxe.
